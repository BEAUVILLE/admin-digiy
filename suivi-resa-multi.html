🧭 Les frontières métier sont claires

🍽️ RESTO : MANGER 🗓️ RÉSA MULTI : RÉSERVER / RDV 🏠 LOC : DORMIR / LOUER

RÉSA MULTI est une porte de découverte vers le professionnel et son moteur métier, pas un logiciel de caisse universel. Une demande de rendez-vous n'est pas une confirmation automatique. Le professionnel garde son calendrier, ses conditions et la relation directe.

🔎 Points à vérifier avant de dire « terminé »

  1. TEST BEAUTY : refaire le parcours client → prestation → sept jours → demande → notification → confirmation/refus côté propriétaire, sur mobile et avec une vraie session de test.
  2. Protection des données : vérifier les droits réellement appliqués dans Supabase, l'accès owner_id, les RPC et l'absence de données personnelles dans la vitrine publique.
  3. Clarté des cartes : le code source contient 7 entrées DEMO mais un libellé traduit annonce « 6 exemples ». Corriger la présentation seulement après validation, sans inventer de professionnels.
  4. Fiches réelles : recontrôler les trois liens chauffeurs et l'état MASTER public ; une entrée REAL dans le code ne démontre pas à elle seule qu'une activité est ouverte aujourd'hui.
  5. Modules complémentaires : beauté et DRIVER disposent de preuves spécifiques ; bien-être, onglerie, événementiel et navette restent des modèles sur la vitrine. Ne pas annoncer un moteur complet de chacun sans test réel.
  6. Déploiement : confronter le contenu de main aux pages effectivement servies avant de parler de livraison publique.
